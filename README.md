# 💰 Enhanced Expense Tracker

A comprehensive iOS expense tracking application with modern features, AI-powered categorization, and beautiful design.

## ✨ New Features & Improvements

### 🎨 **Modern Design System**
- **Consistent Design Language**: Comprehensive design system with colors, typography, spacing, and shadows
- **Dark Mode Support**: Full dark mode compatibility with adaptive colors
- **Enhanced UI Components**: Modern cards, buttons, and form elements
- **Improved Accessibility**: Better touch targets and text sizing

### 🤖 **AI-Powered Features**
- **Smart Categorization**: Automatically categorizes transactions using AI and machine learning
- **Natural Language Processing**: Analyzes transaction descriptions for better categorization
- **Learning System**: Improves accuracy over time based on user behavior
- **Confidence Scoring**: Shows how confident the AI is in its categorization

### 🔄 **Recurring Transactions**
- **Flexible Scheduling**: Daily, weekly, bi-weekly, monthly, quarterly, yearly, and custom frequencies
- **Bill Reminders**: Automatic notifications before due dates
- **Smart Processing**: Automatically creates transactions on schedule
- **End Date Support**: Set expiration dates for recurring transactions

### 📱 **Receipt Scanning**
- **OCR Technology**: Scan receipts using Vision framework
- **Automatic Data Extraction**: Extracts merchant, amount, date, and items
- **AI Categorization**: Automatically categorizes scanned receipts
- **Transaction Creation**: One-tap creation of transactions from receipts

### 🔔 **Smart Notifications**
- **Bill Reminders**: Get notified before recurring payments are due
- **Budget Alerts**: Receive warnings when approaching budget limits
- **Weekly Reports**: Automated financial summaries
- **Custom Reminders**: Set up personalized financial reminders
- **Interactive Actions**: Quick actions from notifications

### 📊 **Enhanced Analytics**
- **Interactive Charts**: Beautiful charts using SwiftUI Charts (iOS 16+)
- **Time Range Filters**: Week, month, and year views
- **Category Breakdown**: Visual spending analysis by category
- **Trend Analysis**: Track spending patterns over time
- **Financial Insights**: AI-generated insights and recommendations

### 📤 **Export & Backup**
- **CSV Export**: Export transaction data for external analysis
- **JSON Backup**: Complete data backup in JSON format
- **File Sharing**: Easy sharing via AirDrop, email, or other apps
- **Data Portability**: Move data between devices

### 🎯 **Advanced Features**
- **Multi-Currency Support**: Track expenses in different currencies
- **Portfolio Tracking**: Monitor investments and mutual funds
- **Goal Setting**: Set and track financial goals
- **Split Transactions**: Handle shared expenses
- **Offline-First**: Works without internet connection

## 🚀 **Getting Started**

### **Prerequisites**
- iOS 15.0+
- Xcode 14.0+
- Firebase project setup

### **Installation**
1. Clone the repository
2. Open `Expense.xcodeproj` in Xcode
3. Configure Firebase (add `GoogleService-Info.plist`)
4. Build and run the project

### **Configuration**
- Set up Firebase project
- Configure notification permissions
- Customize design system colors if needed
